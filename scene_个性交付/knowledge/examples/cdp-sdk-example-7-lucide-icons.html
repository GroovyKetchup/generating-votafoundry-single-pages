CDP-SDK 示例 7：共享 lucide 图标库

演示纯 HTML/JS 个性化页面如何通过 window.semApp.ui.lucide 复用 CDP 宿主已加载的 lucide 图标库，避免在 iframe 内重复打包。

① 检测桥接状态 必读

window.semApp.ui.lucide 由 CDP 宿主加载完 cdp-sdk 后由 LucideBridge 自动桥接而来。仅同源 iframe 生效； 跨域 iframe / 跨域中间层会断链，此时 lucide 为 undefined，需要业务自行降级。 

const lucide = window.semApp?.ui?.lucide;
if (!lucide) {
    // 降级：用占位文字 / 内置 SVG / 不显示图标
}
检测中…

② 用法 A：createIcons() 自动扫描 DOM

给元素加 data-lucide="图标名"（kebab-case），调用 createIcons() 即可一次性渲染所有图标。最适合静态布局。 

<i data-lucide="search"></i>
<i data-lucide="settings"></i>

window.semApp.ui.lucide.createIcons();
search
settings
user
bell
heart
star
check-circle
trash-2

③ 用法 B：编程式 createElement(icons[Name])

拿单个图标节点生成 SVG DOM 元素，插到任意位置。注意键名是 PascalCase（icons.AlertTriangle），与 DOM 扫描的 kebab-case 不同。 

const { createElement, icons } = window.semApp.ui.lucide;
const el = createElement(icons.AlertTriangle);
el.setAttribute('width', 18);
el.setAttribute('height', 18);
container.appendChild(el);

④ 用法 C：按事件动态替换图标

收藏 / 点赞这种切换状态的场景，调用 createIcons 重新扫描即可。

点击按钮：图标在 heart ↔ heart-off 之间切换。
